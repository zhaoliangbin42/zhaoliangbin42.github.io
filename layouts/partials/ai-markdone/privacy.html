{{ if $isEN }}This feature is opt-in.{{ else }}这是一个需要主动开启的功能。{{ end }}

{{ if $isEN }}AI-MarkDone connects to Google Drive only after you choose the Google Drive backup feature and authorize your own Google account.{{ else }}只有当你在设置中选择 Google Drive 备份，并授权自己的 Google 账号后，AI-MarkDone 才会连接 Google Drive。{{ end }}

{{ if $isEN }}AI-MarkDone uses the Google Drive API scope https://www.googleapis.com/auth/drive.file. This scope lets the extension create and manage files it creates or that you open with it; AI-MarkDone does not request broad access to every file in your Drive.{{ else }}AI-MarkDone 使用 Google Drive API 权限范围 https://www.googleapis.com/auth/drive.file。这个权限用于创建和管理 AI-MarkDone 自己创建或你通过它打开的文件；AI-MarkDone 不申请访问整个 Google Drive 的广泛权限。{{ end }}

{{ if $isEN }}When you click backup, AI-MarkDone creates a bookmark snapshot file in your browser and uploads it directly to your Google Drive folder AI-MarkDone/Backups/bookmarks. The snapshot may include the bookmarks you saved, including ChatGPT URL, position, title, folder path, saved time, and saved conversation text. It does not include passwords, OAuth tokens, or extension settings.{{ else }}当你点击备份时，AI-MarkDone 会在浏览器中生成书签快照文件，并直接上传到你的 Google Drive 文件夹 AI-MarkDone/Backups/bookmarks。快照可能包含你保存的书签，包括 ChatGPT URL、消息位置、标题、文件夹路径、保存时间和已保存的对话文本；不包含密码、OAuth token 或扩展设置。{{ end }}

{{ if $isEN }}AI-MarkDone may read back the uploaded file to verify backup integrity, list existing AI-MarkDone backup files, download a selected backup for safe-merge restore, or move an AI-MarkDone backup file to Google Drive trash when you request deletion. These operations are used only to provide backup and restore.{{ else }}AI-MarkDone 可能会读回刚上传的文件以校验备份完整性，列出已有的 AI-MarkDone 备份文件，下载你选择的备份用于安全合并恢复，或在你请求删除时将 AI-MarkDone 备份文件移入 Google Drive 回收站。这些操作只用于提供备份与恢复功能。{{ end }}

{{ if $isEN }}The use and transfer of information received from Google APIs by AI-MarkDone will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.{{ else }}AI-MarkDone 对从 Google API 获得的信息的使用和转移，将遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。英文原文：The use and transfer of information received from Google APIs by AI-MarkDone will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.{{ end }}
