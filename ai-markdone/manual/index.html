AI-MarkDone 手册

详细介绍 AI-MarkDone 的使用方法和提效技巧，按好读、好记、好问、好存梳理 ChatGPT 工作流。

AI-MarkDone 是一个 ChatGPT 浏览器插件。它围绕学习、科研、工作中反复出现的高频痛点而开发，目标很直接：让 ChatGPT 的使用效率得到极致提高。

AI-MarkDone 不是一个玩具。它是一个精简、克制、美观的工作台，专门补足 ChatGPT 在阅读、复制、导出、保存、注释上的短板。装上它，刷新网页，你就能察觉到不同：一系列顺手的工具已经出现在消息页面中。你不需要一直想着它，但在需要的时候，你会自然想到它。

AI-MarkDone 的核心功能可以分成四类：好读、好记、好问、好存。

好读

提供干净的阅读器页面、翻页、消息内导航和 Sticky 栏，一切都为了让你进入心流状态，不受外部影响。

好记

提供高效的内容提取方案：公式复制、消息分享、局部复制，让 ChatGPT 成为科研里的好帮手，不再为内容提取而卡壳。

好问

提供灵动注释和 Prompt 模板。阅读内容时不用盯着输入框，看到哪里，批注到哪里，把提示词抛在脑后。

好存

书签收藏、批量导出为 Markdown、PDF 或 PNG，一切只为了让重要的东西不再遗忘。

类别你遇到的需求对应功能/面板
好读ChatGPT 回答太长，同一个页面内消息太多了，而且还卡顿。Reader 阅读器
好读想要快速切换上一条/下一条消息。消息导航与位置
好读对于长消息，特别是 thinking/pro 级别的长消息，我想看见完整的目录，并且随时跳转到对应的标题。标题大纲
好读发送消息之后，希望保持窗口位置不变。发送后保持位置
好读有重要内容，我想固定住，避免看到下文的时候遗忘。Sticky 临时摘录
好记想把整一条回答都直接粘进 Obsidian、Notion、Typora 等软件内，并且保证格式正确。复制 Markdown
好记我只想带格式地复制回答中的某一小部分内容，包括公式、代码块。局部复制
好记只想拿走一个公式，不想手动框选渲染结果。公式 LaTeX 复制
好记需要把公式作为图片或结构化格式放到文档里。公式 PNG / SVG / MathML
好记想把当前回答变成方便分享的图片。Copy as PNG / PNG 导出
好问读到某句话时，想围绕原文继续追问。灵动注释
好问想将注释的内容整理成 Prompt，直接发送给大模型，完成追问。亦或者经常重复某类追问方式，希望更快组织表达。Reader 发送框
好存得到一条重要的回答，不想以后找不到了。书签保存
好存针对大量的书签，想要进行分类整理或者快速检索。书签管理
好存把好多条回答导出成 Markdown、PDF 或 PNG 格式，易于保存，也易于分享。批量导出
好存换设备或重装前，担心书签数据丢失。Google Drive 备份与恢复

如果你想先看清楚整套插件如何运转，可以从插件层级开始；如果你更想直接上手，就从 Reader 开始。
