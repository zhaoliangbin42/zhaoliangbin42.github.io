## Use this when

You only need a small part of an answer, and you do not want code, tables, or formulas to break while copying.

## Where to open it

Open [Reader](/ai-markdone/en/manual/reader/), then select the text you need inside the Reader body. Use normal system copy or the copy action near the selection.

## How to use it

1. Select a passage in Reader.
2. Copy the selection.
3. Paste into Obsidian, Typora, a Markdown editor, or a document.
4. If the passage includes formulas, code blocks, or tables, try to select the full block instead of cutting through the middle.

## Worth knowing

- Partial copy is for taking a passage with you, not for saving it long term.
- The target editor still decides how Markdown, LaTeX, and tables render.
- If you only want to keep a few passages beside the answer while reading, use [Sticky excerpts](/ai-markdone/en/manual/sticky/).
