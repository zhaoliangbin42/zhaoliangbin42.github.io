## What this solves

The ChatGPT page is good for continuing a conversation. It is not always good for reading one dense answer. Long paragraphs, formulas, tables, and code blocks can crowd the chat view.

Reader rebuilds the current answer as a Markdown reading surface. It keeps you near the original conversation while giving reading, copying, annotation, Sticky excerpts, and follow-up prompts a calmer place.

## When to use it

- The answer has several sections.
- The answer contains formulas, tables, or code blocks.
- You need to copy a precise range.
- You want to annotate exact text.
- You want to keep a few passages beside the answer while comparing them.
- You want to keep reading while sending a follow-up.

## Where to open it

Click Reader from a supported message toolbar in ChatGPT. Reader opens on the current message and lets you move between messages.

## Steps

1. Find the ChatGPT answer you want to process.
2. Click Reader in the message toolbar.
3. Use the pager or Left / Right keys to move between messages.
4. Use Up / Down to scroll the current Reader page.
5. Enable the heading outline in Settings when an answer has many headings.
6. Select content and click Stick when you need a temporary working set.
7. Delete or drag Sticky excerpts to keep them in the order you want.
8. Use the Reader send box for follow-up prompts.

## Common questions

### How is Reader different from the ChatGPT page?

The ChatGPT page is for the next message. Reader is for reading, selecting, copying, annotating, and organizing one answer.

### Is Sticky permanent?

No. Sticky is a temporary excerpt workspace. Use bookmarks for material you want later.

### How is Sticky different from bookmarks?

Sticky is a temporary workspace for comparing passages while reading. Bookmarks are long-term storage for material you want to revisit later.
