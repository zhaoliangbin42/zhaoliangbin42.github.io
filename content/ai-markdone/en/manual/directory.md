## Current status

AI-MarkDone no longer exposes the old right-side directory rail. This page stays in place for older links only; it is not part of the current feature path.

If you are working through a long ChatGPT thread, use the current tools instead:

- To move near the original page, use the lower-right previous/next message stepper, or enable Left / Right arrow-key navigation.
- To read one long answer carefully, open Reader. Reader lets you switch messages, use the heading outline, copy selected Markdown, write annotations, and return to the original ChatGPT message.

## What to use now

1. Use the lower-right previous/next buttons to move between nearby ChatGPT messages.
2. Enable Left / Right arrow-key message navigation in Settings if you prefer keyboard control.
3. Click Reader from the message toolbar when you want to read the current answer carefully.
4. Save a bookmark when the answer is worth finding again.
5. Export to Markdown, PDF, or PNG when the answer needs to leave ChatGPT.

## Next

Continue with the Reader guide. It is the main current entry point for working with long answers.
