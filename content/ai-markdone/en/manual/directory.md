## Current status

AI-MarkDone no longer exposes the standalone directory entry as a public feature. This page stays in place so older links do not break.

If you are working through a long ChatGPT answer, use Reader instead. Reader lets you read the current answer, switch messages, use the heading outline, copy selected Markdown, write annotations, and return to the original ChatGPT message.

## What to use now

1. Find the AI-MarkDone toolbar beside a ChatGPT message.
2. Open Reader for a calmer reading surface.
3. Save a bookmark when the answer is worth finding again.
4. Export to Markdown, PDF, or PNG when the answer needs to leave ChatGPT.

## Next

Continue with the Reader guide. It is the main current entry point for working with long answers.
