局部复制用于取走回答中的一部分。它支持 ChatGPT 原页面和阅读器，两处的快捷键与特殊内容处理方式略有不同。

## 在 ChatGPT 原页面复制

1. 在一条已经生成完成的回答内，选中需要的文字。
2. 点击选区附近的「复制 Markdown」。
3. 粘贴到支持 Markdown 的编辑器中，检查标题、列表或公式的显示。

默认快捷键是 Mac 的 `⌘⇧C`，或 Windows、Linux 的 `Ctrl+Shift+C`。可在设置中将原页面的选区复制快捷键改为 `⌘C` / `Ctrl+C`，也可以关闭此快捷键。

这项操作只处理同一条回答内的选区。跨越两条消息、包含正在生成的回答，或者无法确定来源的选区，不能可靠转换为 Markdown。

## 在阅读器中复制

1. 打开[阅读器](/ai-markdone/manual/reader/)，选中正文中的片段。
2. 使用选区复制按钮，或直接按 `⌘C` / `Ctrl+C`。
3. 粘贴后检查结果。

阅读器里的普通复制快捷键独立于原页面的快捷键设置。想复制整条回答时，使用阅读器顶部的复制按钮，不必拖选全部正文。

## 公式、代码和表格怎么选

| 内容 | 选择方式与结果 |
| --- | --- |
| 普通正文 | 可以选择一句话、一段文字，或同一条回答内连续的多个段落。 |
| 原页面中的公式 | 即使只选中公式的一部分，Markdown 复制也会按完整公式处理，取得对应的 LaTeX。请检查复制结果是否包含了所需的整条公式。 |
| 原页面中的代码片段 | 选区完全位于同一个代码块内部时，复制的是选中的代码文本，保留其中的空格，不添加 Markdown 代码围栏，也不把代码中的符号改写为公式。 |
| 阅读器中的完整代码块或表格 | 选择完整内容块，才能保留相应的 Markdown 结构。 |
| 阅读器中的部分代码或部分表格 | 可能得到所选文字的片段，不能保证它仍是完整、可解析的代码块或表格。对缩进敏感的代码，优先使用代码块自身的复制按钮。 |

如果选区从代码、公式或表格中间开始，又结束在其他内容中，复制可能无法保留完整结构。把选区扩大到完整内容块，通常更容易得到可用的结果。

高亮可以跨表格保存文字，并跳过选区中的代码块、图片或控件；Markdown 复制使用另一套选择规则，不会因为某个范围可以高亮，就自动得到同样的文字片段或完整格式。

## 没出现复制按钮

在设置的「按钮」中检查「选中文字后出现的按钮」。原页面还有「在 ChatGPT 页面显示选区按钮」开关；关闭后，原页面不显示这组按钮。选中文字时出现的边框或底色只是当前选区提示，不表示内容已保存为高亮。

复制只写入剪贴板，不会创建书签或高亮。想暂时对照几段内容，用[摘录区](/ai-markdone/manual/sticky/)；想在以后找到这段文字，用[内容高亮](/ai-markdone/manual/highlights/)。
