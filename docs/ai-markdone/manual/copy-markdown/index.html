复制 Markdown

把完整 ChatGPT 回答或 Reader 选区复制成 Markdown，尽量保留标题、列表、代码块、表格和公式。

这个功能解决什么问题

ChatGPT 自带复制经常只适合临时粘一下。回答里一旦有公式、表格、代码块或引用，粘到 Obsidian、Notion、Typora 里就容易变脏。

AI-MarkDone 做的是另一件事：尽量拿到可继续编辑的 Markdown，而不是只复制屏幕上看见的文字。

什么时候用

  • 想把完整回答放进 Obsidian、Typora、VS Code 或 Git。
  • 只想复制长回答中的几段。
  • 回答里有代码块、列表、表格或公式。
  • 想减少复制后的二次清理。

从哪里复制

  • 整条回答：点消息工具栏里的“复制 Markdown”。
  • 局部内容：先打开 Reader，再选中需要的范围。

具体怎么做

  1. 复制整条回答时，直接点击消息工具栏里的“复制 Markdown”。
  2. 复制局部内容时，先打开 Reader。
  3. 选中你要的段落、列表、表格、代码块或公式。
  4. 使用 Reader 里的复制动作。
  5. 粘贴到你的笔记或编辑器中检查结果。

一条回答是怎么变成 Markdown 的

整条复制走的是一条比较短的链路：

  1. 找到当前这条 ChatGPT 回答。
  2. 刷新当前对话快照，拿到这一轮的 assistant 内容。
  3. 把内容整理成 Reader 使用的 Markdown。
  4. 清掉 ChatGPT 自己的引用标记、内部注释和多余空白。
  5. 统一公式写法，比如把 \(...\) 转成 $...$。
  6. 写入剪贴板。

Reader 里的局部复制稍微不同。它会先判断你选中了哪些 Markdown 单元，比如行内公式、代码块、表格、图片、标题或列表项。选中了完整单元，就复制原始 Markdown；只选了一小段普通文字，就复制这段可见文本。

这也是为什么局部复制建议在 Reader 里做。Reader 比原始 ChatGPT 页面更清楚一段内容属于哪个 Markdown 单元。

支持哪些 Markdown 写法

类型支持情况说明
标题支持# 到 ######
段落支持普通回答文本会按段落保留
加粗、斜体支持**加粗**、*斜体*
列表支持无序、有序、嵌套列表
行内代码支持保留反引号
代码块支持保留 fenced code block 和语言标记
引用块支持保留 >

表格支持使用 GFM 表格
公式支持行内公式和块级公式
图片支持保留 Markdown 图片语法
链接支持保留 [文字](地址) 这种标准 Markdown 链接

常见问题

为什么局部复制要在 Reader 里做？

Reader 能更稳定地知道你选中的内容属于哪个 Markdown 单元。原始 ChatGPT 页面结构更复杂，选区更容易被按钮、引用和隐藏节点打断。

所有内容都能完美还原吗？

不能保证。AI-MarkDone 会尽量保留完整 Markdown 单元，但最终效果还取决于 ChatGPT 当前页面和目标编辑器。
