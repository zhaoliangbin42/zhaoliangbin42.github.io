摘录区

把阅读器中的片段暂存到摘录区，在切换回答时继续对照、调整顺序或移除摘录。

摘录区是阅读器里的临时对照区域。读到后文时，可以把前面的条件、公式或结论留在旁边，不必反复滚动寻找。旧版本中的 Sticky 现在在界面中称为「摘录区」。

暂存一段内容

  1. 从 ChatGPT 回答工具栏打开阅读器 。
  2. 在正文中选中要保留的内容。
  3. 点击选区按钮中的「暂存摘录」。
  4. 摘录区会自动展开，并把这段内容添加到已有摘录的后面。

可以继续选择其他片段。切换到上一条或下一条回答后，已放入摘录区的内容仍然保留，适合比较多条回答中的方案或推导。

整理和收起

使用摘录上的「拖动排序」调整顺序，使用「移除摘录」删除不再需要的片段。拖动摘录区与正文之间的分隔线，可以调整区域宽度。

阅读器底部的「收起摘录区」只隐藏区域，不会删除摘录。需要时点击「展开摘录区」即可继续查看。

摘录会保留多久

摘录保留在当前页面的阅读器会话中。同一页面内关闭阅读器，再重新打开，摘录仍可保留；刷新页面、关闭标签页或重新创建阅读器后，不能依靠摘录区找回这些内容。

它不会把摘录自动写入资料库，也不会创建书签。需要长期保存时，使用高亮 标记原文，或用书签 保存整条回答。需要带到其他编辑器时，使用局部复制 。

为什么有时没有摘录区

摘录区用于从对话中打开的阅读器。通过资料库打开书签预览时，不提供摘录区。两种窗口都能阅读保存的内容，但提供的操作并不完全相同。
