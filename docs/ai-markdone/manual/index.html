AI-MarkDone 使用手册

这份手册只讲插件本身：为什么做、每个入口在哪里、什么时候该用哪个动作。

为什么做这个扩展

最初这个插件只是为了解决我自己的需求而做的。ChatGPT 里真正有用的长回答，经常会遇到三个麻烦：读起来被打断、复制出去要重修格式、过几天又找不到。

因为原网页更适合“聊天”，不一定适合“认真读”。尤其是内容一长，界面里各种按钮、引用、侧边栏和滚动条会让注意力不断被打断。

它补上什么

AI-MarkDone 不重做 ChatGPT 客户端。它留在原页面旁边，只补上 Reader、源码级复制、注释、书签、导出、备份和设置这些整理动作。

阅读器想做的事情很简单：给你一个更安静、更沉浸的阅读环境。

先从眼前这条回答开始

不要把 AI-MarkDone 当成另一个写作应用。它最适合在“这条 ChatGPT 回答已经值得留下”的时候打开，用来阅读、复制、标注、保存或导出。

  1. 从 Chrome Web Store 安装，刷新一次 ChatGPT。
  2. 需要认真读或精确选区时，打开 Reader。
  3. 觉得以后还会用到，就先保存成书签。
  4. 确认内容值得留下以后，再保存书签或导出。

它主要解决的几个场景

如果你经常让 ChatGPT 帮你改文章、润色句子、重写段落，应该很容易遇到一种情况：整段输出里，你只对其中几句不满意。

灵动注释就是为这个场景做的。你可以在阅读器里直接选中任意一句或任意一段，然后点浮出来的注释按钮，把你的修改意见写进去。

我一直觉得，AI 对话里真正有价值的内容，最怕的不是“写不出来”，而是“过两天找不到了”。你会得到一个更像资料库的管理面板。

这个功能的出发点其实很直接：我希望将消息分享这件事变得更简单。像 ChatGPT 原生的分享，很多时候只能分享一个链接。但有些内容你是想拿去发给别人、做笔记、归档，或者直接丢进知识库里的。

我一直不太喜欢那种“功能很多，但全都硬塞给你”的工具，所以这里尽量做成了能自己裁剪的样子。

功能入口速查

阅读器 工具栏 -> 阅读器

把一条长回答放进更安静的阅读面，适合认真读、局部复制和写注释。

源码复制 工具栏 -> 复制 Markdown

复制整条回答，尽量保留标题、列表、表格、代码块和公式边界。

公式点击复制 直接点击消息里的公式

快速拿到单个公式本身，适合贴回 Typora、Obsidian 或文档。

书签保存 工具栏 -> 书签

保存关键回答，并在管理面板里预览、复制、整理和跳回原文。

消息导出 工具栏 -> 导出

把回答导出为 Markdown、PDF、PNG 或多图 ZIP，用于分享、笔记和归档。

字数统计 工具栏右侧统计区

快速判断回答长度，决定是直接读、打开 Reader，还是先保存。

灵动注释 阅读器中选中内容后 -> 悬浮注释按钮

把修改意见落在具体句子上，再整理成可以发给 ChatGPT 的追问。

注释一键复制 阅读器顶部 -> 复制注释

把已经写好的注释整理出来，方便放进笔记或再次修改。

注释一键插入 阅读器左下角发送框上方 -> 插入注释

把注释插回输入框，形成更具体的追问。

书签管理 点击插件图标 -> 书签管理面板

像资料库一样管理已经保存的回答、文件夹和预览内容。

功能开关与配置 书签管理面板 -> 设置

把不用的功能收起来，调整 Reader、公式、注释、导出和界面行为。
