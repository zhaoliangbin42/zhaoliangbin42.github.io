阅读器

打开 ChatGPT 回答的阅读器，调整排版，用标题大纲和分页阅读，并复制、摘录、高亮、写注释或继续提问。

阅读器把一条 ChatGPT 回答单独打开，重新排版其中的标题、正文、列表、代码、表格和公式。读长回答时，可以保留当前阅读位置，同时摘录前文、记录问题和切换回答。

打开一条回答

  1. 等 ChatGPT 完成回答，将指针移到回答底部的 AI-MarkDone 工具栏。
  2. 如果工具栏已收起，先展开，再点击「阅读器」。
  3. 阅读器默认以全屏方式打开。点击右上角的全屏按钮，可以切换窗口大小。

正在生成的回答不能直接打开。按钮不可用时，先等回答完成，并确认这条回答已在页面中加载。

在回答之间移动

底部的上一条、下一条和页码用于切换已收集到的回答。在阅读正文时，也可以用左右方向键切换，用上下方向键滚动。阅读器中的方向键操作不依赖原页面的方向键导航开关。

分页里的数量是当前已收集到的回答数，不代表整段对话的全部历史。很早的回答还没有加载时，先回到 ChatGPT 页面加载对应内容。阅读器会在同一页面使用期间记住阅读位置；刷新页面后，这些位置会重置。

点击底部的定位按钮，可以回到当前回答在 ChatGPT 页面中的位置。定位成功后，页面内的阅读器会关闭。

跳到某一节

回答包含至少两个 Markdown 标题时，阅读器可以显示标题大纲。点击大纲中的标题，跳到对应小节。

如果大纲没有出现，先检查回答是否有足够的标题，再到阅读器右上角「设置」中检查标题大纲开关。仅加粗的句子不一定是 Markdown 标题。

调整阅读方式

打开阅读器右上角的「设置」，调整打开方式、字号、阅读宽度、代码语法高亮和标题大纲。关闭代码语法高亮只会改变代码的着色，不会删除代码内容。

回答在原页面发生变化后，点击阅读器顶部的刷新按钮，重新读取原回答。刷新依赖原来的 ChatGPT 页面仍然可用。

处理正在阅读的内容

想做什么操作与结果
复制整条回答使用顶部复制按钮，取得当前回答的 Markdown。
复制其中一段选中文字后复制。公式、代码和表格的选择规则见局部复制 。
暂时留住前文选中文字后点击「暂存摘录」，放到旁边的摘录区 。
标出以后要回看的句子选择一种高亮颜色 ，高亮会保存到当前浏览器。
写修改意见或问题选中文字后添加灵动注释 。是否在刷新后保留，取决于注释保存设置。
收藏这条回答使用顶部书签按钮，保存回答和对应问题的快照。见书签与资料库 。
继续提问打开左下角发送框，输入问题后点击发送。也可以先插入注释，再检查内容并发送。

关闭后会保留什么

阅读器本身不会把每条打开过的回答自动收藏。摘录区只用于当前页面；高亮会保存在本地；注释则遵循「保存新建的注释」设置。需要长期保存整条回答时，请创建书签。

页面控制中还有实验性的独立阅读器入口。独立阅读器的刷新、发送和定位仍需要来源 ChatGPT 标签页，使用时应保留该标签页。
