备份、导入与迁移资料库

区分完整资料库备份、选中书签导出、消息文件和设置文件，迁移已保存的书签、高亮、注释及文件夹。

本页内容
    • 导出完整资料库
    • 导入并检查合并结果
    • 只导出部分书签
    • 单独迁移设置
    • 删除、卸载与云备份

更换浏览器、迁移设备或卸载扩展前，先导出本地资料库。资料库备份和把一条回答导出成 Markdown/PDF 是两种不同的文件；前者用于恢复已保存的资料，后者用于阅读或编辑。

导出完整资料库

  1. 打开 AI-MarkDone 管理面板。
  2. 进入 设置 → 数据与备份 → 本地备份。
  3. 点击 导出全部，保存生成的 JSON 文件。
  4. 确认下载完成，把文件存放在自己信任的位置。

完整备份包含：

  • 已保存的书签及书签文件夹，包括空文件夹。
  • 已保存的高亮与注释。
  • 这些标记的文件夹和已保存的对话信息。

未持久保存的临时注释、未保存的编辑、Sticky 摘录区、提示词、扩展设置和账号凭据不在资料库备份里。书签若只保存了摘要，备份保留的也是已有摘要，不会自动补成完整回复。

导入并检查合并结果

  1. 先导出一份当前本地资料库，保留导入前的副本。
  2. 在资料库中选择 导入资料库，打开自己的 JSON 备份；文件选择后开始导入和合并。
  3. 导入完成后，查看结果、重复项和冲突提示。
  4. 回到资料库，检查文件夹、搜索、内容预览和几个重要条目。

正常合并会添加文件中的新条目，保留本地独有条目，跳过重复内容；同一条目发生冲突时保留本地版本，不用备份里的版本直接覆盖。

旧版的书签 JSON 仍可导入，但它只恢复书签，不会凭空恢复旧文件里没有的高亮、注释或文件夹内容。格式不受支持或文件损坏时，不要手工删字段强行导入；先保留原文件并查看错误提示。

只导出部分书签

选择书签后导出，文件只包含所选书签。迁移高亮、注释和文件夹时，请使用“导出全部”。

单独迁移设置

进入 设置 → 数据与备份 → 设置文件，导出或导入设置 JSON。导入前可以按分类查看改动；需要回退时，使用这里提供的恢复功能。

设置文件包含外观、按钮显示与固定、阅读和导出等偏好，不包含资料库、对话、提示词、自定义注释模板、Google 账号信息或授权凭据。更换设备时，资料库和设置需要分别处理。

删除、卸载与云备份

资料保存在当前浏览器配置文件中。换浏览器、换配置文件或卸载扩展，不会自动把资料带过去。卸载或清理扩展存储前，先确认备份文件已经保存。

Google Drive 备份 可以保存同样范围的完整资料库，但要手动发起，不能代替实时同步。离线 JSON 和 Drive 备份可能包含你的选中文字、笔记和回复内容；分享文件前先检查其中的信息。
