复制 ChatGPT 公式为 LaTeX、MathML、PNG 或 SVG

用 AI-MarkDone 从 ChatGPT 回答中复制单个公式的 LaTeX 源码，或通过悬浮菜单保存 MathML、PNG、SVG 公式资产。

这个功能解决什么问题

公式复制很容易出错。你可能需要 LaTeX 写进笔记，需要 MathML 粘到 Office，也可能只想把公式作为图片放进文档或幻灯片。

AI-MarkDone 把公式单独处理，不要求你手动框选复杂的渲染结果。

什么时候用

  • 写 Markdown 笔记，需要 LaTeX。
  • 往 Word、PowerPoint 或类似编辑器里粘公式，需要 MathML。
  • 做幻灯片或说明文档，需要 PNG 或 SVG。
  • ChatGPT 回答里的公式在表格中渲染。

从哪里打开

点击公式可以复制源码。PNG、SVG、MathML 等悬浮动作需要先在 Settings 里启用。

具体怎么做

  1. 打开包含公式的 ChatGPT 回答或 Reader。
  2. 只需要源码时，点击公式。
  3. 需要 MathML、PNG 或 SVG 时，先到 Settings 启用对应悬浮动作。
  4. 鼠标悬浮到公式上方。
  5. 选择复制或保存动作。
  6. 粘贴到目标软件中检查效果。

常见问题

LaTeX、MathML、PNG、SVG 怎么选？

Markdown 笔记用 LaTeX。Office 类编辑器优先试 MathML。视觉材料用 PNG 或 SVG。

为什么有些公式动作默认不显示？

公式悬浮动作会增加界面按钮。默认不全开，是为了让工具栏保持干净。
