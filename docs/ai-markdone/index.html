革新你的ChatGPT使用体验。

AI-MarkDone 适合所有 ChatGPT 重度使用者，尤其是理工科科研工作者。把原本零散的复制、截图、导出和批注动作，收进一个更高效的 ChatGPT 工作流。

Reader

阅读器

ChatGPT 原页面适合聊天，但长回答需要一个能静下来读的地方。阅读器把回答放进更清爽的阅读面里，公式、代码和表格保留原样。

  • 阅读面更安静。
  • 代码、表格、公式不打散。
  • 适合论文、推导和长代码说明。

局部 Markdown 复制

选中一段，直接复制成 Markdown。列表、代码和公式尽量保留结构。

灵动注释

读到一句想追问，就把想法写在原句旁边。注释可以继续复制成下一轮 Prompt。

消息切换

在 Reader 里切到前后消息。看长线程时，不用回到原页面重新翻。

Formula

公式复制/导出

遇到单个公式时，不需要从整段 Markdown 里一点点抠。公式悬浮动作可以直接复制 LaTeX，也可以导出 PNG、SVG 或 MathML，写论文、做课件、整理笔记时会省很多手工清理。

  • 复制 LaTeX 源码。
  • 导出 PNG / SVG。
  • 保留 MathML。

  • 文件夹分类。
  • 搜索与预览。
  • 回到原位置。

Export

批量导出

截图、复制、另存、整理，本来会散在很多动作里。AI-MarkDone 把常用导出收进一个流程：Markdown、PDF、PNG、多图 ZIP，以及 Save Messages 这类批量保存方式。

  • Markdown 可继续编辑。
  • PDF / PNG 适合归档。
  • ZIP 和 Save Messages 处理多条内容。

  • 主动连接 Google Drive。

本地优先与信任边界

它是一个克制的扩展，不是另一个内容平台。

信任边界尽量简单：专注 ChatGPT、在浏览器本地完成整理、避免自有后端承接内容，并保持代码公开。

专注 ChatGPT 原页面 目录、Reader、复制、注释和导出都围绕 ChatGPT 的真实使用流打磨。
本地优先 整理动作尽量在浏览器本地完成。只有你主动保存书签时，相关内容才写入扩展存储。
没有自有服务器 AI-MarkDone 没有自建后端承接你的 ChatGPT 内容，也不做使用分析管线。
免费开源 项目保持免费、开源。代码、问题反馈和构建说明都在 GitHub 上公开。
