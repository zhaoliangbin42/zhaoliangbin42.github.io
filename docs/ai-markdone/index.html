BUILT FOR THE IN-BETWEEN

有用的，不只是那次回答。

01

跟完一段推导

把前面的假设留在身边，对照后面的结论。需要引用公式时，复制源码接着写。

02

把疑问留在原句旁

读到哪里，批注到哪里。把针对原文的注释带进下一轮追问，不必重新描述上下文。

03

留下能找回的线索

保存真正帮到你的回答，整理到文件夹。下次需要时，从书签返回原来的对话。

支持哪些网站和浏览器？

AI-MarkDone 专注 ChatGPT。当前公开安装入口是 Chrome Web Store 和 Firefox Add-ons。

复制成 Markdown 能保证格式完全一致吗？

AI-MarkDone 会尽量保留标题、列表、代码、表格和公式。最终效果仍取决于 ChatGPT 当前可用内容，以及目标编辑器对 Markdown 的处理。

Sticky 摘录会永久保存吗？

Sticky 是阅读与对照时的临时工作区。以后还要找回的内容，请保存成书签，或导出成文件。
