这个插件都支持哪些平台？

AI-MarkDone 专注 ChatGPT。当前公开安装入口是 Chrome Web Store 和 Firefox Add-ons。

所有内容都能完美还原吗？

不能保证。AI-MarkDone 会尽量保留完整 Markdown 单元，但最终效果还取决于 ChatGPT 当前页面和目标编辑器。

Reader 里的东西会自动保存吗？

不会。Reader 是阅读和处理当前回答的工作区，Sticky 也是临时的。如果这条内容以后还要找回，请保存成书签；如果要带到别的软件里，请用复制或导出。
