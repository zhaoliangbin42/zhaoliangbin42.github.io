01

Reader 阅读器

原页面适合聊天，不一定适合盯着一段长回答读。Reader 把当前回答拿出来，读完还能回原位。

功能从哪里打开默认 / 状态适合用来
打开 Reader消息工具栏 -> 阅读器工具栏动作打开当前回答的阅读面。长段落、代码、表格、公式都适合先放进去看。
Markdown 渲染与清洗Reader 正文自动处理标题、列表、表格、代码块和公式尽量保留；不安全 HTML 会被清掉。
标题大纲设置 -> 阅读器 -> 显示标题大纲默认开启回答里标题很多时，右侧给一个页内小目录。
大纲跳转与当前标题Reader 右侧标题大纲有多个标题时显示点击标题直接跳转，滚动时也能看到当前读到哪里。
代码块渲染设置 -> 阅读器 -> 渲染代码块默认开启代码回答会按代码块显示；想让 Reader 更轻一点，也可以关掉。
代码块复制Reader 代码块按钮代码块内显示单独复制一段代码，不用从整条回答里重新选。
分页与方向键Reader 底部自动出现同一段对话里有多条回答时，可以一页一页翻，不把全部内容堆成一长条。
全屏阅读Reader 顶部 -> 全屏按钮Reader 动作内容很长、想暂时把 ChatGPT 页面噪音放到一边时打开。
Reader 内容宽度高级设置 -> 阅读器内容宽度默认 1000px，可调 480-1600px屏幕大就放宽一点，想集中读就收窄一点。
定位回原文Reader 底部定位按钮Reader 动作读完以后回到 ChatGPT 原始消息，继续复制、注释或追问。
Reader 内发送Reader 底部 -> 发送Reader 动作把追问或整理好的注释送回 ChatGPT 输入框。
Sticky 临时摘录Reader 选区 -> Stick页面生命周期内保留把几段想对照的内容先钉在旁边。刷新页面后会清空。
Sticky 面板整理Reader 左侧 Sticky 面板可收起、可删除、可拖拽排序读到一半先搭一个临时材料区，之后再决定保存、复制或追问。
02

复制与公式

这里关心的是可复用源码：Markdown、LaTeX，以及不要断在半截的内容块。

功能从哪里打开默认 / 状态适合用来
复制当前消息 Markdown消息工具栏 -> 复制 Markdown工具栏动作只复制当前回答，避免顺手把整页或最后一条消息复制错。
复制当前消息 PNG复制 Markdown 按钮的悬浮动作按浏览器能力显示把单条回答变成一张图片，适合快速发给别人看。
Reader 当前页复制Reader -> CopyReader 动作复制 Reader 当前页，和消息工具栏走同一套内容语义。
Reader 局部源码选区Reader 正文选区 + Cmd/Ctrl+CReader 选区动作只选需要的部分。公式、代码块、表格、图片会按闭合单元拼回源码。
公式点击复制为 Markdown点击公式；可在设置中关闭默认开启点一下公式，拿到原始 LaTeX / Markdown，不用从渲染结果里抠。
公式悬浮动作设置启用后，悬浮单个公式默认全关需要时再打开 PNG、SVG、MathML 复制或保存，平时不打扰阅读。
03

注释与追问

读到某句想改、想追问，就贴着原文写。之后可以把这些注释整理成一段发回 ChatGPT。

功能从哪里打开默认 / 状态适合用来
添加注释Reader 选区 -> 注释Reader 选区动作直接给选中的句子或段落写意见，不用另开文档解释位置。
编辑 / 删除注释Reader 右侧锚点或注释浮层页面生命周期内保留边读边改。注释是临时工作区，刷新页面后会清空。
复制注释Reader 顶部 -> 复制注释有注释时可用把原文片段和你的意见按顺序整理成编号列表。
插入注释Reader 发送浮层 -> 插入注释有注释时可用把整理好的注释放进发送框，少一次复制粘贴。
用户提示词设置 -> 阅读器 -> 用户提示词内置 3 条 starter prompts常用修改要求可以先存好，比如“按注释逐条改”。
注释复制模板设置 -> 阅读器 -> 注释复制模板默认包含选中文字与用户注释占位符决定复制注释时的输出格式。
提示词位置设置 -> 阅读器 -> 将提示词放在注释下方默认放在上方按自己的习惯，把提示词放在注释前面或后面。
04

书签与资料管理

有些回答当下不一定马上用，但以后肯定会找。书签保存内容，也保存回去的路。

功能从哪里打开默认 / 状态适合用来
一键保存 / 取消书签消息工具栏或 Reader 顶部 -> 书签工具栏动作保存关键回答，同时记录回到原文所需的位置。
保存弹窗与文件夹保存书签时可用给书签命名，放进项目、主题或写作任务对应的文件夹。
搜索与排序书签面板排序支持时间与 A-Z按关键词、时间或字母顺序找回保存内容。
书签预览点击书签行复用 Reader不先跳回原页面，也能在面板里快速看一眼内容。
Go / Copy / Delete书签行操作可用回原文、复制内容、删除旧书签，都在同一行处理。
批量删除、移动、导出书签面板多选后可用一次整理多条书签，适合项目结束后收拾资料。
导入 / 导出备份书签面板或数据与存储JSON 文件重装浏览器、换设备或大改动前，先导出一份。
仅保存部分文本设置 -> 工具栏与页面操作默认关闭，保存 500 字符想省存储空间时打开。预览会变短，但仍能跳回原文。
05

导出与分享

需要放进笔记、发给别人、归档到项目里时，再把 ChatGPT 消息导出去。

功能从哪里打开默认 / 状态适合用来
Save Messages消息工具栏 -> 导出 / 另存为默认显示打开导出弹窗，默认定位到当前回答，也可以手动多选。
Markdown 导出Save Messages -> Markdown可用适合放进笔记、仓库、文档，后面继续编辑也方便。
PDF 导出Save Messages -> PDF浏览器打印链路适合交付定稿、保存长回答，或者保留阅读版式。
PNG / ZIP 导出Save Messages -> PNG单条为 PNG，多条打包 ZIP单条回答发图，多条回答打包。教程、汇报、群聊都能用。
PNG 图片宽度设置 -> 工具栏与页面操作默认电脑 800px；手机 390、平板 640、自定义 360-1200按分享位置调宽度：手机截图、桌面文档、网页素材都不一样。
PNG 图片倍率设置 -> 工具栏与页面操作默认 1x，可调 1x-3x想更清楚就调高倍率；长图太大时会为了稳定自动收一点。
Deep Research 清洗Markdown / 导出链路自动处理导出 Deep Research 内容时，尽量少带无用噪声。
06

设置项速查

日常使用默认值就够。想裁剪工具栏、调 Reader、改 PNG 导出或者改一点界面细节，再来这里找。

分组设置项默认 / 可选值会影响什么
平台在 ChatGPT 上启用扩展默认开启这是主开关。网站和文案也按 ChatGPT-first 来讲。
平台Chrome / Firefox 安装入口Chrome Web Store / Firefox Add-ons公开安装入口只放这两个，避免用户误会支持面。
工具栏消息导出默认显示决定工具栏里是否显示“另存为”。
工具栏字数统计默认显示显示当前消息或 Reader 内容的字数、字符数。
书签仅保存部分文本默认关闭；保留 500 字符省空间用。代价是书签预览会变短。
公式公式点击复制为 Markdown默认开启点击公式即可复制原始 LaTeX / Markdown。
公式公式悬浮动作默认全关；可开 PNG/SVG/MathML 复制和 PNG/SVG 保存需要公式图片或 MathML 时再开，不让按钮长期挡阅读。
Reader渲染代码块默认开启Reader 里显示格式化代码块；关闭后用占位降低渲染压力。
Reader显示标题大纲默认开启内容有多个 Markdown 标题时，在右侧显示小目录。
Reader提示词放在注释下方默认关闭决定复制注释时，提示词出现在注释前还是后。
Reader用户提示词内置 3 条 starter prompts，可增删改把常用改稿要求存起来，下次不用重写。
Reader注释复制模板唯一模板，含选中文字与用户注释 token决定注释复制后的文本长什么样。
导出PNG 图片宽度手机 390 / 平板 640 / 电脑 800 / 自定义 360-1200决定导出图片卡片的宽度。
导出PNG 图片倍率默认 1x，可调 1x-3x决定清晰度。长图太大时仍可能自动降级。
ChatGPT发送后保持当前位置默认关闭读历史消息时发送新消息，尽量别被带到底部。
语言界面语言自动 / English / 简体中文跟随浏览器语言，也可以手动固定。
数据存储占用设置页显示查看扩展当前占了多少本地存储。
数据导出全部手动按钮卸载、重装、换设备前，先把书签导出。
高级全局字号默认 16px，可调 12-20px调整 AI-MarkDone 自己的界面文字大小。
高级主题色默认蓝；可选翡翠绿、紫罗兰、玫瑰红、琥珀色调整按钮、链接、焦点环和选中状态的强调色。
高级阅读器内容宽度默认 1000px，可调 480-1600px调整 Reader 正文最大宽度。
