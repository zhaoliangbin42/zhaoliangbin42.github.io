AI-MARKDONE / WORKFLOW

读懂，提取，
留给以后。

AI-MarkDone 把一次 ChatGPT 回答接进你的工作：认真读，带走需要的部分，再保存值得回看的内容。

先看见结构，再读懂细节。

长回答不该只剩下一直滚动。Reader 把正文、标题大纲和消息切换放在一起，Sticky 摘录留住暂时需要对照的公式与结论。

走进 Reader

带走需要的部分，接着写。

选中段落，复制为 Markdown；拿走一个公式的 LaTeX 源码，或导出公式图片。尽量保留结构，让下一步整理轻一点。

阅读公式指南

值得回看的内容，有处可寻。

将具体回答保存成书签，按文件夹整理、搜索，再返回原始对话。需要离开浏览器时，可以导出为 Markdown、PDF 或 PNG。
