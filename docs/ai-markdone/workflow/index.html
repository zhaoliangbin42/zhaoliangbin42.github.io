工作流

按步骤使用阅读器、批注、书签和公式工具，并完成消息导出与资料库备份。

读完一条长回答，整理阅读笔记

例如，你让 ChatGPT 解释 FFT，回答里包含 DFT 公式、复杂度对比表和几个小节。

  1. 在这条回答的工具栏点击“阅读器”。
  2. 在右侧标题大纲中选择要读的小节。大纲来自回答里的 Markdown 标题；没有标题的回答不会自动生成完整章节。
  3. 遇到后面还要对照的内容，选中它，在选择工具栏中点击“暂存摘录”。摘录区会自动展开，和正文一起查看。
  4. 想把片段放进笔记时，选中内容并复制 Markdown。公式、代码等内容尽量按完整单元选择。
  5. 读完后，用底部消息切换按钮继续看其他回答，或关闭阅读器回到 ChatGPT。

摘录区是临时的，刷新页面后会清空。需要长期保留整条回答，请保存书签 ；需要带走一部分，请局部复制 。

标出疑问，带着原文继续追问

例如，一篇改写稿里有三句话需要调整。你可以逐处写意见，再把引用和意见一起交给 ChatGPT。

  1. 在原页面或阅读器中，选中需要讨论的文字。
  2. 在选择工具栏中点击注释，写下具体问题，例如：“这句话太笼统，请补充一个实际例子。”
  3. 点击“保存注释”，或按 Ctrl+Enter / ⌘+Enter 提交当前注释。仅输入文字或失去焦点不会自动提交；关闭编辑器会丢弃未保存的内容。
  4. 重复标注其他位置。在阅读器中，顶部“复制注释”整理的是当前回答的注释，选择提示词并复制后，需要自行粘贴到输入框；要整理整段对话，在原页面输入框旁打开“注释”，选择“当前对话”，再点击“插入到输入框”。
  5. 检查输入框里的原文与问题，再发送给 ChatGPT。常用的开场白和每条注释的组合格式，可以在提示词与注释模板中调整。

如果只是想标出重点，使用高亮 。它支持在同一条回答内跨段落、表格单元格选择，也可标记部分行内代码。完整且有可靠源码的公式可以随混合选区保存；未完整选中的公式、代码块、图片等不支持的内容会跳过，保留周围文字。注释点击保存后是否长期保留，还取决于“保存新建的注释”设置；未开启时，它只保留在当前页面。详见灵动注释 。

保存回答，之后从资料库找回

例如，你想保存 FFT 与 DFT 的对比说明，下次查看时不用重新翻整段对话。

  1. 在回答的工具栏点击书签，在弹出的窗口中填写标题、选择文件夹，然后确认保存当时的提问和回答。
  2. 打开资料库，在书签列表中继续修改标题或移动文件夹。
  3. 下次打开资料库，按标题或内容搜索，选择条目预览已保存的内容。
  4. 需要接着讨论时，使用返回原文的操作打开原对话。对话仍需存在，且当前账号能够访问。
  5. 高亮和已保存注释分别在资料库对应的视图中查找。

资料库中的保存内容和返回原文是两件事。保存的回答可以预览，但原对话删除、账号切换或网页内容变化，可能使定位失败。详细说明见书签与资料库 。

输入公式，确认排版，再复制到文档

例如，你想在 ChatGPT 输入框里写分式或多行公式，先确认表达式没有写错。

  1. 打开设置中的输入与提示词配置，确认输入增强和公式预览已开启。
  2. 在输入框中用 $…$ 写行内公式，或用 $$…$$ 写独立公式。在公式内输入反斜杠，选择 LaTeX 命令补全。
  3. 用上下方向键选择补全项，按 Tab 或 Enter 插入。带占位的片段可以用 Tab / Shift+Tab 切换要填写的位置。
  4. 把文字光标放在公式中，查看跟随光标出现的预览。预览无法生成时，先检查括号、定界符和命令。
  5. 预览就绪后，使用对应动作复制或保存 PNG、SVG，或复制 MathML。发送给 ChatGPT 前，再检查输入框里的 LaTeX 源码。

输入中的公式和回答中的公式分别配置。点击回答中的公式可以直接复制源码；需要 PNG、SVG 或 MathML 悬浮操作时，再在设置中开启对应按钮。完整选项见输入框公式 和回答中的公式 。

把回答整理成 Markdown、PDF 或图片

例如，你需要把几条相关回答整理到 Obsidian 中，或者分享给同事。

  1. 只需要一条回答时，使用消息工具栏中的 Markdown 复制；只需要一段时，使用局部复制。
  2. 需要多条回答时，打开消息导出，勾选要保留的消息。导出会按顺序包含这些条目中可取得的提问和回复。
  3. 选择 Markdown、PDF 或 PNG。Markdown 用于继续编辑；PDF 和 PNG 用于阅读和分享。
  4. 所选回答含有图表或卡片时，PDF、PNG 会显示保留图片或文字占位选项。需要离线保留这些内容时，使用 Markdown 离线 ZIP；支持的图表和卡片会打包为静态附件。
  5. 查看生成结果。PDF 通过浏览器打印界面保存；PNG 生成一张或多张图片，多张图片会打包下载。

复制后的显示效果取决于目标软件的 Markdown 和数学公式支持。导出前，请确认勾选范围；PDF、PNG 的细节和图片加载条件见批量导出 。

换设备前，备份资料库

  1. 在设置的数据页面，导出本地资料库备份。它包含书签、文件夹、高亮和已保存注释。
  2. 在另一台设备安装扩展，导入备份，完成后检查导入结果、重复项和冲突提示。
  3. 如果使用 Google Drive，在支持授权的浏览器中连接自己的账号，再手动点击立即备份。
  4. 从 Drive 恢复时，先选择快照并查看预览。连接账号本身不会自动上传，也不是实时同步。

扩展设置与资料库是两类数据。希望同时迁移按钮、阅读和导出偏好时，还需要单独导出设置。详见本地备份与恢复 、Google Drive 备份 及配置项总表 。
