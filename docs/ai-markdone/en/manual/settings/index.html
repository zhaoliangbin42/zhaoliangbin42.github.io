Settings

Hide unused actions and tune Reader, formula actions, exported images, backup, and interface preferences in AI-MarkDone Settings.

Overview Install Directory Reader Copy Formulas Annotations Bookmarks Export Settings

What this solves

AI-MarkDone has many actions, but you probably do not use all of them every day. Too many buttons can make the original ChatGPT page feel noisy.

Settings trims the interface. Keep your common actions and hide the rest.

When to use it

  • The toolbar feels too full.
  • You want to adjust Reader width or heading outline.
  • You need formula MathML, PNG, or SVG actions.
  • You want to tune PNG export width or scale.

Where to open it

Open the extension panel and switch to Settings. Chrome and Firefox expose extension permissions a little differently, so a few actions appear only when the current browser can run them reliably.

Steps

  1. Open the AI-MarkDone extension panel.
  2. Go to Settings.
  3. Choose whether to show Save Messages, word count, and context-only save in Toolbar & Page Actions.
  4. Configure Reader: code rendering, heading outline, annotation prompts, and content width.
  5. Enable formula MathML, PNG, or SVG actions if needed.
  6. Adjust PNG export width and scale.
  7. Use Data Management for local export or Google Drive backup.
  8. Return to ChatGPT and refresh or reopen Reader to confirm the change.

Common questions

What should I turn off first?

Turn off actions you never click. If you mainly read and copy, Reader, Copy Markdown, and bookmarks may be enough.

Why are some actions different between browsers?

Chrome and Firefox do not handle clipboard, download, and extension-page permissions in exactly the same way. AI-MarkDone tries to show only the actions that are stable in the current browser.
