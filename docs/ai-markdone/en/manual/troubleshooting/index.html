Troubleshooting

Check AI-MarkDone when the toolbar is missing, copy/export looks wrong, or bookmarks and backups need attention.

On this page
    • Toolbar does not appear
    • Copy or export looks wrong
    • Bookmarks and backup
    • Send a useful report

Toolbar does not appear

Start with the simple checks:

  1. Make sure you are on the ChatGPT page.
  2. Refresh the ChatGPT tab.
  3. Open the browser extension manager and confirm AI-MarkDone is enabled.
  4. Check that the extension can access the current site.
  5. If ChatGPT has just loaded or updated, wait for the page to settle and check again.

Copy or export looks wrong

The final result also depends on the editor you paste into. Check it this way:

  1. Paste into a plain Markdown editor first and see whether the source is complete.
  2. If formulas look wrong, confirm that the target editor supports LaTeX.
  3. If PNG export is too long or too large, lower the export width or scale.
  4. If PDF export looks wrong, check the browser print preview settings.

Bookmarks and backup

  1. Confirm the bookmark appears in the bookmark manager.
  2. Export a local backup before making major changes.
  3. Before restoring from Google Drive, confirm you are using the same Google account.
  4. Keep a copy of the current data before restore, so you have a way back.

Send a useful report

If you send a report, these details help:

  • Browser name and version.
  • AI-MarkDone extension version.
  • The page or button where the problem happens.
  • Screenshot or screen recording.
  • Short steps to reproduce.
  • Relevant console error, if you know where to find it.

Public issues are best on GitHub Issues . For private notes, email zhaoliangbin42@gmail.com.
