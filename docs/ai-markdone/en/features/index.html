01

Reader

The ChatGPT page is good for chatting. It is not always good for reading one dense answer. Reader gives that answer its own calmer surface, then lets you return.

FeatureWhere to openDefault / stateGood for
Open ReaderMessage toolbar -> ReaderToolbar actionOpen the current answer in Reader. Long paragraphs, code, tables, and formulas are easier to read there.
Markdown rendering and cleanupReader bodyAutomaticHeadings, lists, tables, code blocks, and formulas are preserved where possible. Unsafe HTML is removed.
Heading outlineSettings -> Reader -> Show Heading OutlineOn by defaultWhen an answer has several headings, Reader shows a small outline.
Outline jump and active headingReader outline railShown when multiple headings existJump to a heading and keep track of the current section while scrolling.
Render code blocksSettings -> Reader -> Render Code BlocksOn by defaultCode answers render as code blocks. Turn it off when you want a lighter Reader.
Code block copyReader code block buttonShown inside code blocksCopy a code block directly instead of selecting it from the full answer.
Pagination and arrow keysReader footerAutomaticMove through answers one page at a time instead of turning the Reader into one endless scroll.
Fullscreen readingReader header -> fullscreen buttonReader actionUse it when the answer is long and you want the surrounding ChatGPT page out of the way.
Reader content widthAdvanced Settings -> Reader content width1000px default, adjustable 480-1600pxWiden it on a large display, narrow it when you want tighter reading.
Locate source messageReader footer locate actionReader actionReturn to the original ChatGPT message after reading, then copy, annotate, or ask a follow-up.
Send from ReaderReader footer -> SendReader actionSend a follow-up or prepared annotation text back to the ChatGPT composer.
Sticky temporary excerptsReader selection -> StickKept for the page lifetimePin a few passages beside the Reader while you compare them. They clear after refresh.
Sticky panel organizationReader left Sticky panelCollapsible, deletable, draggableBuild a temporary working set while reading, then decide what to save, copy, or ask about.
02

Copy and formulas

Copying should keep usable source: Markdown, LaTeX, and content blocks that do not break halfway.

FeatureWhere to openDefault / stateGood for
Copy current message MarkdownMessage toolbar -> Copy MarkdownToolbar actionCopy the current answer, not the whole page or the last visible message by accident.
Copy current message as PNGHover action on Copy MarkdownShown when browser policy allowsTurn one answer into an image when that is easier to share.
Copy current Reader pageReader -> CopyReader actionCopy the current Reader page using the same content rules as toolbar copy.
Source-aware Reader selectionReader body selection + Cmd/Ctrl+CReader selection actionSelect only what you need. Formulas, code blocks, tables, and images are copied as closed source units where possible.
Formula click copies MarkdownClick a formula; configurable in SettingsOn by defaultClick a formula and get its LaTeX / Markdown source without digging through the rendered output.
Formula hover actionsHover a formula after enabling actions in SettingsAll off by defaultEnable PNG, SVG, or MathML copy/save only when you need those assets.
03

Annotations and follow-up

When one sentence needs a note or follow-up, write next to the source text. Later, turn those notes into a prompt.

FeatureWhere to openDefault / stateGood for
Add annotationReader selection -> AnnotateReader selection actionComment on the selected sentence or paragraph without describing its location in another document.
Edit / delete annotationReader gutter anchor or annotation popoverKept for the page lifetimeRevise notes while reading. They are temporary and clear after a full refresh.
Copy annotationsReader header -> Copy annotationsAvailable when annotations existBuild a numbered list from the source snippets and your notes.
Insert annotationsReader send popover -> Insert annotationsAvailable when annotations existPlace prepared annotations into the send box and skip a copy-paste step.
User promptsSettings -> Reader -> User promptsThree starter prompts includedSave common revision instructions, such as editing point by point.
Annotations copy templateSettings -> Reader -> Annotations copy templateDefault template includes selected source and user annotation tokensDecide the format used when annotations are copied.
Prompt positionSettings -> Reader -> Place prompt below annotationsPrompt on top by defaultPut the prompt before or after the annotation list.
04

Bookmarks and saved material

Some answers are not needed right now, but you know you will look for them later. Bookmarks save the content and the way back.

FeatureWhere to openDefault / stateGood for
Save / remove bookmarkMessage toolbar or Reader header -> BookmarkToolbar actionSave an important answer and the location needed to return to it.
Save dialog and foldersWhen saving a bookmarkAvailableName a bookmark and place it in a folder for a project, topic, or writing task.
Search and sortBookmarks panelSort by time or A-ZFind saved material by query, time, or alphabetic order.
Bookmark previewClick a bookmark rowUses ReaderPreview saved content in the panel before jumping back to the source page.
Go / Copy / DeleteBookmark row actionsAvailableJump to the source, copy content, or remove an old bookmark from the same row.
Bulk delete, move, exportAfter selecting bookmarks in the panelAvailableClean up multiple bookmarks at once, useful when a project wraps up.
Import / export backupBookmarks panel or Data & StorageJSON fileExport a copy before reinstalling the browser, switching devices, or making big changes.
Context-only saveSettings -> Toolbar & Page ActionsOff by default, keeps 500 charsTurn it on to save storage. Previews are shorter, but source-page navigation still works.
05

Export and sharing

When an answer needs to go into notes, a project archive, or someone else's inbox, export it.

FeatureWhere to openDefault / stateGood for
Save MessagesMessage toolbar -> Export / Save asShown by defaultOpen the export dialog at the current answer, then select more messages if needed.
Markdown exportSave Messages -> MarkdownAvailableUse it for notes, repositories, documents, or any workflow where editing continues.
PDF exportSave Messages -> PDFBrowser print flowUseful for a finished handoff, archived long answers, or preserving a readable layout.
PNG / ZIP exportSave Messages -> PNGSingle item as PNG, multiple items as ZIPShare one answer as an image, or package several answers as a ZIP.
PNG image widthSettings -> Toolbar & Page ActionsDesktop 800px default; mobile 390, tablet 640, custom 360-1200Set width for the destination: mobile screenshots, desktop docs, and web assets do not need the same size.
PNG image scaleSettings -> Toolbar & Page Actions1x default, adjustable 1x-3xRaise the scale for sharper output; very long exports may be capped for stability.
Deep Research cleanupMarkdown / export pipelineAutomaticWhen exporting Deep Research content, the pipeline trims avoidable noise.
