A FEW ANSWERS

A few things to know.

Read all answers
Which websites does AI-MarkDone support?

AI-MarkDone is focused on ChatGPT. The public installation links are the Chrome Web Store and Firefox Add-ons.

Will Markdown copy always preserve everything?

AI-MarkDone tries to preserve headings, lists, code, tables, and formulas. The result still depends on the content available in ChatGPT and how the destination editor interprets Markdown.

Are Sticky excerpts saved forever?

Sticky is a temporary workspace for reading and comparison. Use bookmarks for content you want to find later, or export it to a file.
