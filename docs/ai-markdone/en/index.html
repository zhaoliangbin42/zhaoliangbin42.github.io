Feature guide

Change how ChatGPT fits into your work.

AI-MarkDone is for heavy ChatGPT users, especially researchers and STEM workers. It brings scattered copying, screenshots, exports, and annotations into a more efficient ChatGPT workflow.

Reader

Reader

ChatGPT is great for conversation, but long answers need a quieter surface. Reader keeps formulas, code, and tables intact in a focused reading view.

  • A quieter reading surface.
  • Code, tables, and formulas stay intact.
  • Better for papers, derivations, and long code explanations.
More in Reader

Partial Markdown copy

Select a passage and copy it as Markdown, with lists, code, and formulas kept as clean as possible.

Precise annotations

Leave a note beside the exact sentence you want to question, rewrite, or turn into the next prompt.

Message switching

Move between nearby messages inside Reader instead of scrolling back through the original thread.

Formula

Formula copy/export

When you only need one formula, you should not have to dig it out of a whole Markdown block. Formula actions let you copy LaTeX or export PNG, SVG, and MathML for papers, slides, and notes.

  • Copy LaTeX source.
  • Export PNG or SVG.
  • Keep MathML available.
Bookmark

Bookmarks

Useful AI answers are easy to lose a few days later. Bookmarks keep the answer and its source position, with folders, search, preview, and a path back to the original spot in ChatGPT.

  • Folder organization.
  • Search and preview.
  • Jump back to source.
Export

Batch export

Screenshots, copying, saving, and cleanup usually become separate chores. AI-MarkDone brings common export paths together: Markdown, PDF, PNG, multi-image ZIP, and Save Messages for batch saving.

  • Markdown stays editable.
  • PDF and PNG archive cleanly.
  • ZIP and Save Messages handle batches.
Backup

Google Drive backup

When bookmarks start to matter, local storage deserves a safer copy. Connect your own Google Drive to back up AI-MarkDone bookmark snapshots, then restore with safe merge instead of overwriting local data.

  • Connect Google Drive yourself.
  • Back up bookmark snapshots.
  • Restore with safe merge.
Settings

Settings

AI-MarkDone is meant to be trimmed to your habits instead of pushing every button into view. You can tune the toolbar, formula actions, Reader width, font size, theme color, and export image width so the tools you actually use stay close.

  • Trim the toolbar.
  • Tune Reader appearance.
  • Set formula and export actions.

Local-first trust

A focused extension, not another content platform.

The trust model is deliberately simple: focus on ChatGPT, do the work in the browser, avoid an owned backend, and keep the code public.

Built around ChatGPT Directory, Reader, copy, annotation, and export are shaped around real ChatGPT use.
Local-first Work happens in the browser. Related content is written to extension storage only when you choose to save a bookmark.
No owned server AI-MarkDone has no owned backend receiving your ChatGPT content and no usage analytics pipeline.
Free and open source The project stays free and open source, with code, issues, and build notes visible on GitHub.
