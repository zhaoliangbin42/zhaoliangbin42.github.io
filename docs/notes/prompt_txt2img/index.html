摘要

悉尼歌剧院人物风景图

版本：Google Gemini 3 Nano Banana Pro

不要换脸，人物脸部稍微卡通化，但要保持高度一致性！整体都需要保持人脸相似度，略微内扣身体，拍摄角度为远处第三人拍摄，典型的日韩视觉自拍风格。简洁干净，进一步凸显人物主体。整体画面清晰度高，最终呈现出精致、时尚、略带的合影效果。要求人物实现无缝融进画面，视觉过渡自然，整体画面光线明亮且均匀，将人物置身于《疯狂动物城》风格的3D动物城市，在我身后是悉尼歌剧院和悉尼港大桥，保留原始图片中的人物，但转换为风格化的拟人化基础设施，8K 画质，比例1:1
